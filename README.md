# Blog

## Quick Start

Install hugo in its [releases](https://github.com/gohugoio/hugo/releases) page or by package manager.

Then, clone this repository with its all submodules.

```sh
$ git clone --recurse-submodules -j8 git@github.com:vanJker/vanJker.github.io.git blog
```

## Usage

```sh
# Run the blog in local
$ ./run.sh
# Commit all changes [with ammend]
$ ./commit [-a]
# Fetch and merge latest commit of blog [and theme PaperMod]
$ ./pull.sh [-t]
```
